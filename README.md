# Chef's Menu Manager

## Project Description

Chef's Menu Manager is a React Native mobile
application developed to help restaurant chefs
manage their menu items efficiently.

## Technologies Used

- React Native
- TypeScript
- JavaScript
- VS Code

## Features

- Add menu items
- View menu items
- Edit menu items
- Delete menu items
- Search menu items
- Filter by course
- View menu statistics
- Input validation and user feedback

## How to Run the Application

1. Clone the GitHub repository.
2. Install project dependencies using npm install.
3. Start the project using the appropriate
   command for the existing React Native setup.
4. Run the application on the configured device
   or emulator.
